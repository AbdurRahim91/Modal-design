# 🪟 Modern Modal Design Hub & UI Component Library

An interactive, production-ready showcase of **31 modern HTML5 & CSS3 modal/popup dialogs**. Featuring clean glassmorphic interfaces, WAI-ARIA accessibility, animations, bottom drawers, and a centralized code explorer.

---

## 🌟 Key Features

- **31 Diverse Modal Designs**: Ranging from simple alerts and cookie banners to complex multi-step wizards, bottom drawers, and command palettes (Cmd+K).
- **Interactive Showcase (`index.html`)**: Live iframe previews for every modal, instant search filter, syntax viewer, and single-click "Copy Code".
- **Centered Viewport Previews**: Test any modal in a centered screen overlay backdrop.
- **Zero Heavy Dependencies**: Built purely with semantic HTML5, modern CSS3 (Flexbox, CSS Grid, Custom Properties, Backdrop Filters), and vanilla JavaScript.
- **Modular Data (`modals-data.js`)**: Clean architecture separating data/code templates from presentation.

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/AbdurRahim91/Modal-design.git
   cd Modal-design
   ```
2. Open `index.html` directly in your web browser:
   ```bash
   # Linux
   xdg-open index.html
   # macOS
   open index.html
   ```
3. Click **"Live Demo"** on any card to test the modal centered on screen, or click **"Copy Code"** to use it directly in your project.
